# 행동 데이터 기반 개인화 채용공고 추천 프로토타입

사용자의 최근 구직 행동을 기반으로 관심 직무를 결정하고, 동일 직무 공고 중 **원격근무 가능 / 연봉 공개** 속성을 우선 반영해 TOP5를 추천하는 프로토타입입니다.

## 프로젝트 흐름

1. 최근 30일 사용자 행동 추출
2. 관심 직무 결정
   - 실제 지원 직무가 있으면 우선 사용
   - 없으면 keywords + specialty + tag 기반 추정
3. 동일 job_field 공고 후보 생성
4. 사용자 기준일 이후 생성된 미래 공고 제외
5. 이미 지원한 공고 제외
6. 원격근무 가능 / 연봉 공개 공고 우선 재정렬
7. 동일 점수에서는 최신 공고 우선
8. 동일 회사 중복 최소화
9. TOP5 추천

## 주요 기준

### 최근 30일
14일은 최근성은 높지만 활용 가능한 사용자가 적고, 60일은 30일 대비 개인화 가능 사용자 증가폭이 2.87%p에 그쳤습니다. 오래된 관심사가 섞일 가능성을 고려해 최근성과 데이터 확보 수준의 균형이 좋은 30일을 사용했습니다.

### 탐색값-직무 매핑 기준 10 / 0.8
탐색값 최소 10회 등장 + 대표 직무 비율 80% 이상을 기준으로 사용했습니다. 20 / 0.8로 강화하면 Accuracy 상승은 0.55%p에 그친 반면 Coverage는 3.07%p 감소하여 10 / 0.8을 선택했습니다.

## 재정렬 효과

| 지표 | 재정렬 전 | 재정렬 후 |
|---|---:|---:|
| 원격근무 가능 공고 비율 | 16.56% | 99.21% |

> 98.48%는 추천 정확도가 아니라, 최종 TOP5 추천 공고 중 원격근무 가능과 연봉 공개 조건을 모두 만족한 공고의 비율입니다.

## attribute_score

- 2점: 원격근무 가능 + 연봉 공개
- 1점: 두 조건 중 하나만 충족
- 0점: 두 조건 모두 미충족

이 점수는 추천 정확도 점수가 아니라 **상단 배치 우선순위 점수**입니다.
